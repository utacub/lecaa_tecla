## Reproducció

```sh
python tools/build.py dist/LECAA-Tecla.html
python tools/pwa.py
node tools/qa-release.cjs
```

Playwright ha de ser resoluble per Node; `LECAA_CHROMIUM` pot indicar un executable Chromium. L’arnès prepara una còpia local de la PWA anterior mitjançant Git i utilitza un perfil temporal a localhost. No fa servir dades d’alumnes reals. Els originals de producció i els punts de recuperació complets es conserven als arxius privats del projecte.

## Publicació des del codi font

El workflow de GitHub Pages compila l’HTML i la PWA en cada push a main. Els HTML generats i el service worker no es versionen: les versions per utilitzar i descarregar es serveixen a GitHub Pages. `tools/pwa.py --keep-icons` reutilitza les icones versionades, de manera que el desplegament només requereix Python estàndard. El muntatge local per defecte continua regenerant les icones amb Playwright.
